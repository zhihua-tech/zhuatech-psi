# 企业进销存管理系统企业能力

## 领域覆盖

- **商品资料**：维护SKU、条码、规格、单位、税率、批次和保质期
- **采购管理**：处理采购申请、订单、到货、退货和供应商交期
- **销售管理**：管理报价、订单、发货、退货、价格和客户信用
- **库存台账**：按组织、仓库、库位、批次维护可用和锁定库存
- **调拨与盘点**：完成调拨、盘点、损溢审批和账实差异闭环
- **批次效期**：执行先进先出、保质期预警和批次追溯
- **往来结算**：生成应收应付、收付款、核销和客户供应商对账
- **成本核算**：支持移动平均成本、毛利和库存金额分析
- **经营分析**：分析采购、销售、周转、滞销、缺货和利润

## 横向控制基线

- ADMIN 与 OPERATOR 权限分离，管理员审批由服务端强制校验；
- 模块白名单、字段约束、唯一编号、乐观锁和合法状态迁移；
- 企业控制项支持组织、期间、责任人、风险、期限和幂等键；
- 经办与复核职责分离，办结前至少登记一份带 SHA-256 的业务凭证；
- 外部系统同步保存成功、失败、回执编号和审计详情；
- 支持组合检索、分页、逾期筛选、CSV 导出、评论与时间线；
- `/api/domain/decision` 对企业进销存管理系统关键场景返回决策、0–100评分、计算指标和处置动作；
- prod profile 对默认账号密码、数据库口令和不安全跨域来源执行启动门禁。

## 生产适配

真实 `ERP`、IAM、消息、对象存储和第三方供应商接口只预留集成边界，由部署企业自行配置。生产上线前必须完成权限矩阵、数据映射、容量压测、灾备演练、安全评估与用户验收。
